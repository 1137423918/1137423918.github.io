使用已有Python3.11和uv，在解压目录运行；冻结依赖同步会联网下载，随后本项目wheel安装使用offline/no-deps。服务只监听本机loopback：

uv sync --python python3.11 --project runtime --frozen \
  --no-install-project --no-default-groups
uv pip install --python runtime/.venv/bin/python --offline --no-deps \
  ./agentlab_evidence-0.1.0-py3-none-any.whl
uv pip check --python runtime/.venv/bin/python
runtime/.venv/bin/agentlab-evidence --root reports \
  --manifest reports/catalog.json --check
runtime/.venv/bin/agentlab-evidence --root reports \
  --manifest reports/catalog.json --port 18856

--check逐份检查报告哈希后退出，不监听端口；正常启动也先检查。客户端连接http://127.0.0.1:18856/mcp，结束时停止前台服务。可用自有可信目录与manifest替换数据，格式见启动包示例及完整使用文档。

六个工具，同一份固定来源

工具职责
begin_audit创建随机审计句柄、给出快照及额度
list_reports列出可信目录；描述文字不作为事实
read_report读取1–8个JSON pointer，返回来源SHA和回执
verify_assessment精确JSON值/类型、引用及所提交回执覆盖核对
audit_status查看已用操作和读取计数，不重领额度
close_audit释放上下文，额度耗尽后也能关闭

MCP2.3.0负责工具发现和Streamable HTTP消息传输；上下文、回执和额度由本项目实现。报告固定在公开commit2c977ec...，其中116项是当时的工程快照，新130结果不倒填。

边界也写进接口

默认32个活跃上下文，每个600秒TTL、16次有代价业务操作、8次已发回执读取；目录/读取内部7168字节、业务结果8192字节、请求体16384字节，MCP封装可能更大。参数层提前拒绝和状态/关闭不记作昂贵业务操作，这不是全HTTP限流或模型费用预算。

句柄是可分享的审计能力，不是用户身份认证或SDK会话ID。回执证明持有读取结果，不证明理解了内容。进程内状态有界，TTL在后续访问时清理；不承诺多机/掉电恢复。事实核对仍明确返回verdict_truth_verified=false及free_prose_semantics_verified=false，不能把JSON事实校验当作所有解释都正确。
