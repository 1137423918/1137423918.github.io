异步 Agent 也共用持久额度

异步组件阶段增加独立 asyncio/HTTPX2 客户端，复用原请求账本与存储准入，打包为 8.4KB wheel；现有维护 worker 继续同步执行。完整服务器回归 116 项通过、零跳过，包含 8 项新增异步检查，不再加一次 focused 数量。

在独立环境中实际接入 Pydantic AI 2.71.0 / OpenAI SDK 3.57.0 / HTTPX2 2.16.2。四场假服务控制共 8 次 POST、3250 字节，工具实际读取已公开报告。使用脚本回复，不是模型推理或自主修复成绩。

线程执行账本读写，取消时等未完成的持久化操作结束；网络等待可取消。取消可能在发包前已消耗额度，持有文件锁时也可能延迟返回，不承诺固定取消时延。首次创建必须使用新目录，恢复提供原账本 ID；账本丢失拒绝重建，避免把已用额度清零。

首轮两项检查因冷启动未到故障注入边界而失败，原日志保留；增加独立启动就绪检查后通过。另一次无网络探针发现初始化误重建缺口，已修正并验证安装后的 wheel。中间绿色版本未发布，未把早期失败改判成功。服务器实测请求哈希/字节与账本匹配，四份账本原样保存；完整对话请求体未持久保存，不能据此独立复原全量载荷。

只覆盖 asyncio 和本机 loopback chat-completions POST；关闭重定向、环境代理和连接重试。次数/JSON 字节不是 token 或费用，不提供工具恰好一次执行、恶意所有者防护、掉电或跨主机恢复保证。框架环境隔离，原 worker 的 68 项依赖版本未改。

早期同步实现：先预留，再发送

HTTPX transport 获取SDK最终序列化的JSON体，检查请求次数、单次体字节和累计体字节。预留经锁、fsync和原子替换持久化后才发送；任务manifest绑定账本身份、额度与任务哈希。SDK重试关闭，恢复不会自动重领额度。

触发情况处理
503、超时、未知在途请求保留预留，不退款
额度不足发送前拒绝，不增加HTTP
多轮修复与重启共用父任务账本
账本丢失或意外损坏停止，不静默重置
完成结果缓存复用不新增模型请求

异步生成与流式入口也明确拒绝，避免绕过同步客户端。账本仅记录请求哈希、字节数与传输观察，不保存headers或API key。收到响应头不是模型完成证明；崩溃也可能发生在预留后、发送前，因此计数有意偏保守。

在真实仓库中强杀，再恢复

固定Deep Agents 744a797e，使用相同的两处参考编辑。正常运行与第一条工具checkpoint后SIGKILL/恢复，分别限制最多3次HTTP请求。恢复保留原来的账本ID，不重复第一处编辑；两场都恰好3次HTTP，JSON体分别8726、9224、10218字节，累计28168字节；哈希与字节数逐条匹配预留，最终请求体序列和补丁哈希均一致。

各场分别通过113条固定原版测试、119条候选测试和28个独立契约；这些验收组有重叠，不累加成一个总数。操作者给出正确编辑，不能把成功验收写成模型自主修复成绩。

74项回归，其中11项针对预算故障

新增检查覆盖真实在途SIGKILL、503和超时跨重启记账、单次与累计字节上限、修复候选共享额度、缺失/损坏账本、缓存与异步入口。六个实际进程争抢三份额度时，三个获准、三个拒绝。

新独立环境安装jsonschema后，此前跳过的14项解析检查也实际执行，所以完整结果从历史的49通过/14跳过变为74通过/零跳过，不能简单当作新增25项。最初三项失败来自验证子进程找不到未安装的项目包；原日志保留，修正独立环境的editable安装后再跑最终测试，没有削弱断言。

可以写进简历，也要写清单位

实现了跨重启、跨修复轮次的模型HTTP请求预算，并用真实故障和仓库验收验证。上限的单位是请求次数与JSON请求体字节，不是token、费用、生成质量或端到端耗时；不承诺请求恰好执行一次。该早期阶段仅准备了Qwen3.5预算预设；后续实际神经试验及其失败另见模型维护记录。

文件锁和fsync依赖文件系统语义；本轮不声称多主机、掉电恢复或抵御恶意所有者篡改账本。同步worker只连接loopback推理服务。
