ENGINEERING PROJECT

Agent Reliability Lab

Python / Deep Agents / LangGraph / SQLite / Git worktree / HTTPX

A software-maintenance runner with durable state, resource limits and reviewable evidence for interrupted tasks, repeated requests and unreliable acceptance.

  • Connect SQLite checkpoints and isolated Git worktrees to retain tool progress and failed candidates. On local ext4, normal and first-checkpoint SIGKILL runs produce the same reference patch; reject NFS before writes or cached success.
  • Add task-scoped file inventory, content-hash-checked source navigation and frozen original-test acceptance. Check Python syntax before export and validate patch, log and feedback hashes before reusing success.
  • Reserve HTTP attempts and JSON bytes durably before send, shared across restarts and repair rounds. Exercise real loopback HTTP with 503s, timeouts, in-flight SIGKILL and competing processes.
  • Fix detached and double-forked verifier leaks and stale installed-supervisor loading. Reap Linux descendants before releasing the worker lock. All 108 engineering checks pass with zero skips, including two new checks.
